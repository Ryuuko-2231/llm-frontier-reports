  - 中文摘要：RoLaQ 针对多头潜在注意力（MLA）的 KV cache 在 2-bit 量化下的误差问题，提出一种离线联合旋转与范围校准方法：在冻结的 key/value 投影所定义的子空间内优化共享旋转矩阵，并联合学习量化阈值与重建增益，使注意力匹配和 value 读出误差同时受控；在三个 MLA 模型、六个基准上取得对比方法中最高的平均准确率，并在 DeepSeek-V2-Lite 的 SGLang 实现中于相同显存预算下把 BF16 KV 容量提升到 3.96 倍、256K 输入时解码吞吐提升到 2.51 倍。

  - 中文摘要：该论文将注意力指数核展开为 n 项截断泰勒级数，并把每一项分解为张量幂内积，从而把因果历史压缩为恰好 n 个循环状态，每个 token 仅用一次秩一外积更新，状态更新与上下文长度 N 无关。递归对截断核是无损的（float64 下误差 2.2e-16），状态可跨块相加，因此预填充可用并行扫描。实测 softmax 注意力耗时约 N^2.28，而该方法约 N^0.91，交叉点在 N≈728，N=8192 时加速 20.8 倍；逐 token 解码延迟恒定为 7.3 微秒，N=65536 时相对 softmax 加速 76 倍。精度随 n 指数改善，但第 m 个状态宽度为组合数，成本组合增长，最优为二阶 n=3，误差 6.5e-4，每头 9945 个元素；查询和键归一化是前提。

  - 中文摘要：论文系统研究稀疏自编码器（SAE）需要多少激活数据，在 3 个语言模型、4 种 SAE 架构上从 5M 到 500M token 预算训练，发现功能指标（如重建）往往在小预算下就接近全量参考，但特征的一对一可复现性持续随数据增长；例如 Gemma-2-2B BatchTopK 的严格匹配特征比例从 5M 时的 2% 升到 50M 时的 29%，数据选择策略（随机 vs 多样性）也分别影响重建与 AutoInterp。

- [P0] [Same Answer, New Box: How Much of RLVR's Out-of-Domain Gain Is Answer Format?](https://arxiv.org/abs/2610.20639)（arXiv cs.LG · 论文 · 评测与安全 · 新 · 2026-10-16）
  - 中文摘要：论文质疑 RLVR 的域外增益有多少来自答案格式而非真实能力提升。作者用公开代码中的答案抽取器与自研抽取器（同时读取 \boxed{} 和正文中的明确答案）对四个 7B SimpleRL 基座-RL 配对重新评分，发现这些抽取器报告的域外多选题增益中 82% 在自研抽取器下消失，独立 LLM 阅读器给出 77%，提示要求放入 box 时该比例为 79%。
