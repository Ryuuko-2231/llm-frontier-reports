  - 中文摘要：论文提出 OLIVE（OnLine InterVEntion），一种在线蒸馏方法：每轮由当前学生策略生成前缀，教师自回归续写，学生只在教师生成的 token 上计算交叉熵并更新。该方法针对离线 SFT 的序列协变量偏移、token 级 on-policy 蒸馏在前缀失败时的监督碎片化、以及分布匹配蒸馏需要教师 token 概率等问题；在推理和 agentic 任务上，相同 GPU 小时预算下优于 OPD（top-16 KL 近似），异步实现进一步减少 23.8% 训练时间，并在离线蒸馏平台期后继续提升，同时更好保留通用能力。
  - 亮点：用学生状态下的教师续写替代固定教师轨迹，既缓解协变量偏移，又避免依赖教师 token 概率，在同等算力下持续提升推理表现。
  - 注意：方法依赖教师模型在线生成，训练基础设施和工程复杂度较高；异步实现可能引入 staleness，论文未充分讨论超参敏感性和教师质量下降时的鲁棒性。
  - 学习指引：重点看 OLIVE 的迭代流程、前缀生成与教师续写的交互方式、损失计算位置，以及异步实现如何降低训练时间；实验部分关注与 OPD、离线 SFT 的对比设置、推理与 agentic 任务指标、通用能力保留的评测，并思考其与 RLHF/RLVR 的关系。
  - 优先级依据：后训练与对齐是当前大模型算法工程师的核心技能，OLIVE 直接针对蒸馏与在线策略优化，可能影响学习路线和项目选题，值得当天重点看。

  - 中文摘要：论文指出 RLVR 提供可靠的轨迹级信用，OPSD 提供 token 级密集监督，但两者耦合了步级信用的方向与幅度，使更新容易受教师判断错误和偏好方差影响。作者提出 DCSD（Decoupled Credit Self-Distillation），通过 belief-margin probing 确定信用方向、marginal information gain 量化信用幅度，将方向与幅度解耦并用于校准特权教师监督，实现步到 token 的信用分配。在 11 个基准上，DCSD 总体优于 GRPO、OPSD、RLSD、RLCSD，数学推理提升 8.45 分、多模态推理提升 7.01 分，并纠正了 6% token 的信用方向。
