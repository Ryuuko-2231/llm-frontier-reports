  - 中文摘要：论文提出 Phronix，一种以能力为中心的 Agent 学习范式，让 Agent 的 harness 从自身执行中获取、验证和精炼可复用能力。它采用 predictor-validator-corrector 循环：MCP 工具与技能提出方案，工具执行验证，结果反馈用于精炼能力库；遇到失败任务会继续研究而非放弃。实验显示学到的能力在首次尝试中解决重复任务的成功率达 93-95%，并降低解的非确定性。
  - 亮点：把 Agent 的每次执行蒸馏为可复用能力，并用执行结果闭环验证，减少重复试错。
  - 注意：摘要未说明能力库的泛化边界与长期维护成本，93-95% 可能只在特定重复任务分布上成立。
  - 学习指引：重点看能力库的数据结构、predictor-validator-corrector 循环如何落地为代码，以及 MCP 工具与 skill 的接口设计；关注实验中的任务类型、模型规模和 93-95% 指标的统计口径；同时留意 harness 与模型解耦的系统设计。
  - 优先级依据：直接涉及 Agent 工具使用与自主能力积累，对构建 Agent 项目有强参考价值，值得当天重点看。

  - 中文摘要：论文提出 MisconceptDialogue，一个全自动框架，用 5 个 7B-14B 开源 LLM 导师与 LLM 模拟学生进行 5000+ 多轮对话，检测、诊断并纠正数学误解。核心发现是评测标准会显著改变结论：同一批对话上，精确匹配式评分给出 42.1% 的补救成功率，而人工校准的 LLM-as-judge 给出 81.3%，差距达 39.2 个百分点，超过导师模型、教学策略和诊断信息等因素的合计影响。
