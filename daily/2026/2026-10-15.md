- [P0] [ActionOPD: Distilling Decisions, Not Tokens](https://huggingface.co/papers/2610.19820)（Hugging Face Daily Papers · 论文 · 后训练与对齐 · 新 · 2026-10-15 · Huining Yuan, Xiangmin Yi, Zelai Xu）
  - 中文摘要：这篇论文提出 ActionOPD，一种面向语言模型智能体蒸馏的动作级在线策略蒸馏方法。作者认为传统离线模仿学习存在状态分布不匹配问题，而 token 级在线蒸馏又依赖教师模型的 token 概率和兼容分词器。ActionOPD 改为在学生在策略中遇到的状态上，从学生和黑盒教师分别采样语义动作，根据学生动作与教师动作的语义一致性给予奖励，再通过策略优化对齐学生的动作级行为，无需复现教师的推理文本或访问教师 token 概率。实验在 Qwen3-4B 和 Qwen3-8B 上使用两个教师模型进行训练。
  - 亮点：把监督粒度从 token 提升到语义动作，使智能体蒸馏不再需要教师 token 概率和兼容分词器，更适合黑盒教师场景。
  - 注意：语义动作的划分和一致性判断可能依赖额外模型或启发式规则，会引入新的偏差；论文摘要未说明在复杂多步工具调用任务上的表现，需关注其适用范围。
  - 学习指引：重点看方法部分如何定义“语义动作”以及如何计算学生动作与教师动作的语义一致性奖励；关注在线策略采样与策略优化的具体实现，尤其是如何避免依赖教师 token 概率。实验部分应关注与离线模仿、token 级 OPD 的对比，以及不同教师模型和不同学生规模下的效果。代码若开源，值得研究其动作采样和奖励计算模块。
  - 优先级依据：该工作直接针对后训练与对齐中的智能体蒸馏问题，方法思路清晰且可能影响小模型智能体训练实践，值得当天重点阅读。
- [P0] [KV4-RL: Unlocking Faster Asynchronous Rollouts for RLVR with INT4 KV Cache Quantization](https://huggingface.co/papers/2610.14448)（Hugging Face Daily Papers · 论文 · 推理部署与性能优化 · 新 · 2026-10-15 · Sihwan Park, Sung-Yub Kim, Doohyuk Jang）
  - 中文摘要：这篇论文研究 RLVR 训练中异步 rollout 的 KV 缓存量化加速问题。作者发现异步 rollout 会提高并发度，使上下文处理集中在更少的解码步中，从而显著增加每步 KV 负载；在此场景下，KV 缓存量化比仅权重量化和权重激活量化带来更大加速。但直接使用 INT4 KV 缓存会损害学习效果，即使采用 token 级截断重要性采样。为此作者提出 KV4-RL，结合免校准 INT4 KV 量化与对 attention sink 和近期上下文的选择性 INT8 保护，在保留大部分加速的同时减少采样器不匹配。在 Qwen3-8B-Base 的 GRPO 训练中，400 次迭代累计 rollout 加速 1.80 倍，全迭代加速 1.27 倍，最终六个基准平均准确率与 BF16 rollout 相差 0.5 个百分点以内。
  - 亮点：发现异步 RLVR 训练中 KV 缓存量化收益远大于权重和激活量化，并用选择性 INT8 保护解决了 INT4 带来的学习退化。
  - 注意：实验主要基于 Qwen3-8B-Base 和 GRPO，结论在其他模型规模、RL 算法和硬件上的泛化性仍需验证；INT4 量化对长尾生成质量的影响可能未被完全覆盖。
  - 学习指引：重点看问题刻画部分，理解异步 rollout 为何导致 KV 负载集中；关注 KV4-RL 的量化方案设计，特别是哪些位置被保护为 INT8 以及保护数量如何选择。实验部分应关注加速比与准确率之间的权衡、与 BF16 和纯 INT4 的对比，以及不同训练迭代阶段的稳定性。
  - 优先级依据：该工作同时涉及 RLVR 训练效率和推理部署优化，对理解大模型训练与推理系统协同设计很有价值，属于当天应重点阅读的工程实践类论文。

- [P0] [Latent Compaction with Test-Time Training](https://huggingface.co/papers/2610.20582)（Hugging Face Daily Papers · 论文 · 模型架构与预训练 · 新 · 2026-10-15 · Yingfa Chen, Xingyu Shen, Chaojun Xiao）
  - 中文摘要：这篇论文提出 Latent Compaction，一种通过测试时训练学习紧凑文档特定 KV 缓存的方法。长上下文会增大 KV 缓存，增加生成时的内存和注意力开销，而压缩缓存必须保留信息以回答未见问题。该方法先用重建重要性、教师注意力和键空间多样性初始化缓存条目，然后训练缓存拟合完整缓存的注意力输出和对数归一化器，再通过端到端蒸馏联合优化整个缓存。模型权重保持冻结，训练只使用关于文档的通用提示，不访问下游问题和答案。在 RULER、LongBench 和 Phonebook Lookup 上，该方法显著优于预算匹配的压缩基线，例如在 RULER 上 32 倍压缩达到 96.7% 准确率，而 KVZip+ 为 40.0%，并且可跨模型规模和家族迁移。
  - 亮点：把 KV 缓存视为可测试时训练的神经网络，在 32 倍压缩下仍保持 96.7% 的 RULER 准确率，远超现有压缩基线。
  - 注意：测试时训练需要额外计算开销，可能抵消部分推理加速收益；方法依赖通用文档提示，对需要复杂推理的下游任务效果仍需验证。
  - 学习指引：重点看方法部分，理解如何用测试时训练把 KV 缓存当作可训练神经网络来压缩；关注缓存初始化策略、两阶段训练目标和端到端蒸馏的具体设计。实验部分应关注不同压缩率下的准确率、与基线方法的对比，以及跨模型迁移的验证。
  - 优先级依据：该工作属于模型架构与预训练中的长上下文和 KV 缓存优化方向，方法新颖且实验提升显著，对理解长上下文推理效率有重要价值，值得当天重点阅读。
