- [P0] [When EOS Tokens Disagree: Understanding Length Inflation in On-Policy Distillation](https://huggingface.co/papers/2609.20511)（Hugging Face Daily Papers · 论文 · 后训练与对齐 · 旧 · 2026-09-18 · Yuxiao Yang, Tianrun Yu, Shangzhe Li）
  - 中文摘要：这篇论文研究在线策略蒸馏（On-Policy Distillation, OPD）中出现的“长度膨胀”现象：学生模型在蒸馏后回复变得过长，甚至耗尽生成预算。作者发现一个重要原因是基座学生模型与后训练教师模型在终止符（EOS）上存在不匹配——即使两者声明的停止集合相同，实际把停止概率放在不同的 EOS token 上。这种不匹配会抑制学生偏好的终止动作，同时又无法可靠地传递教师偏好的替代终止动作。实验覆盖 Qwen3、Llama 和 Gemma 三个模型家族，表明仅对齐解码停止集合不够，而把功能等价的 EOS token 视为共享的语义停止动作能显著缓解长度膨胀。作者还按 K2-Horizon 训练阶段分析终止行为演化，发现训练中终止偏好会大幅漂移，并在 OPD 后期出现一种与终止对齐无关的独立长度膨胀。
  - 亮点：把“功能等价的 EOS token 应视为同一语义停止动作”这一洞察用于缓解蒸馏中的长度膨胀，视角新颖且工程可操作。
  - 注意：论文聚焦终止符层面的机制，OPD 后期仍存在无法用终止对齐解释的长度膨胀，说明长度控制还有其它未解因素；结论主要基于三个模型家族，迁移到其它架构或蒸馏配方时需重新验证。
  - 学习指引：重点看问题定义与 EOS 不匹配的度量方式、三个模型家族上的对照实验设计，以及“共享语义停止动作”这一干预手段的实现细节。阶段分析部分值得关注训练动态如何影响终止行为，并思考该现象是否也出现在你使用的蒸馏或 RLHF 流程中。建议结合代码或复现实验，检查自己训练管线里 tokenizer 的 EOS 配置与解码停止集合是否一致。
  - 优先级依据：直接关系后训练与蒸馏实践中的常见故障（输出过长、预算耗尽），对学习路线和工程调试有即时价值，值得当天重点阅读。

  - 中文摘要：这篇论文关注 LLM 助手在社交咨询场景中的推理能力评测难题：助手需要从主观的用户叙述中理解社交情境，而他人意图等社交属性通常缺乏可验证的 ground truth。作者提出 Fuse，一个多智能体模拟框架：一个带有隐藏动机的目标智能体与其他智能体（包括代表用户的智能体）交互，用户随后咨询被评测的助手来推断目标动机，从而在构造上提供可验证的 ground truth。作者用 24k 条人工标注验证了模拟的忠实度，并在 12 个 LLM 上应用 Fuse，系统性地隔离关键因素，发现：用户中介会加剧社交推理的固有难度；LLM 对带偏见的用户表述存在系统性敏感；模型有时需要比人类更多的细节才能做出正确预测；更长的对话并不总能提升表现。
  - 亮点：通过多智能体模拟构造出可验证的社交推理 ground truth，并系统揭示用户中介、用户偏见表述和对话长度对 LLM 社交推理的影响。
  - 注意：模拟环境与真实社交咨询仍有差距，人工验证的忠实度不等于真实场景有效性；结论基于 12 个 LLM 的特定版本，且社交推理的“正确答案”本身可能带有标注者主观性。
  - 学习指引：重点看 Fuse 的多智能体模拟设计、ground truth 如何“按构造”保证可验证，以及 24k 人工标注的忠实度验证方法。实验部分值得细读四个发现对应的消融与隔离实验，思考这些结论对 Agent 在真实咨询场景中的可靠性意味着什么。可借鉴其评测范式用于自己的 Agent 项目。
  - 优先级依据：Agent 评测与可靠性是当前热点，论文提供了可复用的多智能体评测框架和反直觉发现，对项目选题和评测设计有直接启发，值得当天重点看。

  - 中文摘要：这篇论文提出 FAMOS，一个从稀疏、无序的部分点云集合中预测可动部件分割与关节参数的前馈模型。现有前馈方法多从单次观测推断关节结构，严重依赖学到的类别级形状先验。FAMOS 联合推理多次观测，天然支持可变数量的输入（包括单视图）。为聚合跨观测的关节线索，作者提出 Multi-state Articulation Transformer，交替使用状态级注意力和全局注意力；并提出 observed articulation span 目标，监督每个部件在输入观测中表现出的运动范围，鼓励模型利用完整观测集。为克服现有数据集规模和多样性不足，作者还引入程序化数据生成器，在训练中合成自标注资产。在 PartNet-Mobility、ACD 和 ArtiCraft-10K 上取得一致提升。
  - 亮点：用交替的状态级与全局注意力联合推理多次稀疏观测，并配合观测运动范围监督，使前馈模型摆脱对单视图类别先验的过度依赖。
  - 注意：属于 3D 关节物体建模，与主流大语言模型算法工程师的日常关联较弱；程序化生成数据的域差距和真实场景泛化能力仍需验证。
  - 学习指引：重点看 Multi-state Articulation Transformer 的注意力设计（状态级与全局如何交替）、observed articulation span 目标的定义与监督方式，以及程序化数据生成器如何合成自标注资产。实验部分关注稀疏观测数量变化时的鲁棒性和与单视图基线的对比。
  - 优先级依据：方法有借鉴意义（多观测聚合、数据生成），但方向偏 3D 视觉，与大模型算法工程师核心路线关联中等，适合泛读。
