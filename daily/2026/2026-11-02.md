- [P0] [Youtu-Parsing-Omni: One Encoder, One Schema, All Modalities](https://huggingface.co/papers/2610.39301)（Hugging Face Daily Papers · 论文 · 后训练与对齐 · 旧 · 2026-10-30 · Yunhang Shen, Zhangquan Chen, Xiaotian Li）
  - 中文摘要：该论文提出 Youtu-Parsing-Omni，一个全模态解析器，用单一编码器（Youtu-Omni-Encoder，从预训练语言模型初始化）将文档、图像、音频和视频编码到统一的时空坐标系，并用统一输出模式 OmniSchema 覆盖十种解析任务；在此基础上提出 OmniSchema-Aware On-Policy Distillation（OSAD），让模型在自身 rollout 上以参考模型 token 级目标进行自演化后训练，使解析器与监督信号共同进化，最终以 5B 参数单检查点取得 SOTA。
  - 亮点：用“一个编码器 + 一个 schema + 自演化 on-policy 蒸馏”把十种多模态解析任务统一进单次后训练流程，而不是为每个任务单独建模。
  - 注意：摘要只给出 SOTA 结论，未说明各任务的具体指标、数据规模与 OSAD 的稳定性；自蒸馏循环存在参考模型漂移和训练不稳定的风险，需看正文消融。
  - 学习指引：重点看三部分：一是统一编码器如何用共享权重处理多模态并做跨模态融合（视频帧 attend 同时段音频）；二是 OmniSchema 如何把十种任务统一成同一 token 角色目标；三是 OSAD 的 on-policy 蒸馏循环——参考模型如何随训练权重刷新、token 级目标如何构造。实验部分关注多任务之间的相互促进与 5B 规模下的效率取舍。
  - 优先级依据：多模态统一解析与自演化后训练是当前后训练方向的前沿工程范式，对理解统一 schema 和多任务对齐很有参考价值，值得当天重点看。

  - 中文摘要：论文把 Platonic Representation Hypothesis 从猜想变成定理：证明分别在不同模态上训练的 JEPA，只要正样本对是同一场景的两个“好视角”，学到的表示至多相差一个旋转；并指出 next-token prediction 是“坏视角”下的 JEPA，这解释了语言模型为何只能靠规模与视觉对齐。作者用 14.5 万 caption 到 9.4 亿网络图像文本验证理论，发现对齐的 scaling law，且好视角达到同等对齐所需样本比 NTP 少 42 倍，109M 参数的文本 JEPA 对齐 DINOv2/CLIP 优于所评估的语言模型。
