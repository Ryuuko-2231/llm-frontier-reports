- [P0] [VerifierBench: Benchmarking the Generation of Executable Verifiers for LLM Agents](https://huggingface.co/papers/2610.28679)（Hugging Face Daily Papers · 论文 · Agent 与工具使用 · 新 · 2026-10-22 · Jianing Yin, Ziyi Chen, Hao Wang）
  - 中文摘要：该论文研究“验证器生成”：给定任务指令和环境，让 Agent 编写可执行验证器，要求其接受所有有效解并拒绝无效解。作者提出 VerifierBench，包含来自六个 Agent 基准的 222 个任务，覆盖工具调用、状态和代码验证，含 4993 个隐藏测试用例（包括替代有效解和攻击），并用 Verifier4Verifier 六项审计筛查源验证器和测试套件。在 19 个模型上，归一化平衡准确率仅 10.6 到 62.1，生成验证器拒绝无效解比接受有效解更可靠，但这种“强项”可能掩盖过度严格的验证：多数假拒绝来自不接受任何测试解的验证器，且错误假设解格式、工具使用和代码变更会排除有效解，自测也难以发现。
  - 亮点：揭示 Agent 生成验证器普遍“拒绝强、接受弱”，且过度严格验证会被高拒绝率掩盖。
  - 注意：基准任务和隐藏测试规模有限（222 任务、4993 用例），验证器质量高度依赖底层模型和 Agent harness，结论不宜直接外推到所有验证场景。
  - 学习指引：重点看验证器生成的任务定义、VerifierBench 的隐藏测试构造（替代有效解与攻击用例）、V4V 审计流程，以及假拒绝和过度严格验证的分析。对做 Agent 训练数据过滤、RL 验证信号或工具调用评测的读者，应关注如何设计既不过严也不过松的可执行验证器。
  - 优先级依据：Agent 与工具使用方向，验证器生成直接关系到 Agent 训练数据过滤和可靠输出校验，属于值得当天重点看的方法论工作。
- [P0] [Bridged Self-Distillation for On-Policy Learning](https://huggingface.co/papers/2610.26397)（Hugging Face Daily Papers · 论文 · 后训练与对齐 · 新 · 2026-10-22 · Runsheng Chen, Yihong Liu, Raoyuan Zhao）
  - 中文摘要：该论文提出 Bridged Self-Distillation（BSD），一个从任意能提供推理轨迹的教师模型进行 on-policy 蒸馏的统一框架。外部教师先离线生成推理轨迹作为特权上下文；学生在不含该上下文的条件下生成 rollout，而一个以该上下文为条件的“学生副本”作为自教师，在学生自己的 token 空间中对同一 rollout 打分。BSD 用这些 token 级指导调整失败 rollout 的更新，并由验证器提供结果信号。由于外部教师只用于生成文本，同一训练流程适用于共享分词器、跨分词器等不同教师场景。
  - 亮点：用学生自身条件副本作为自教师，绕开强教师 token 概率不可用或分词器不兼容的问题。
  - 注意：依赖外部教师生成高质量推理轨迹和验证器提供可靠结果信号；自教师打分可能继承学生自身偏差，跨分词器场景的实际收益需看实验细节。
  - 学习指引：重点看方法设计：特权上下文如何构造、自教师如何在同一 token 空间打分、验证器结果信号如何与 token 级指导结合，以及跨分词器场景的处理。实验部分应关注与 on-policy 蒸馏基线的对比、失败 rollout 的利用效率，以及教师质量对学生的影响。
  - 优先级依据：后训练与对齐方向，on-policy 蒸馏是提升小模型推理能力的关键技术，方法统一且实用，值得当天重点看。

  - 优先级依据：评测与安全方向，面向 Agent 科研能力的前沿基准，对理解开放式 Agent 评测设计和能力边界有重要参考价值。

  - 中文摘要：该论文提出分层稀疏注意力（SSA），用于缓解长上下文推理中 KV cache 注意力成本瓶颈。现有稀疏注意力在确定性检索（捕获高分 token 但丢弃残余注意力质量）与采样（覆盖更好但方差更高）之间存在权衡，混合 top-k 加均匀采样在极端稀疏下仍与稠密注意力有明显差距。SSA 将确定性检索与分数引导采样统一起来：确定性地关注高分 token，同时用代理注意力分数对残余部分采样，并按包含概率做修正，从而恢复检索集之外的注意力质量。SSA 涵盖 top-k、top-p 和混合 top-k+采样作为特例。在 RULER、LongBench、LOFT 和 AIME 上，5 个 3B 到 27B 模型在匹配稀疏度下均优于基线。
  - 亮点：用分数引导采样加包含概率修正，在极端稀疏下缩小与稠密注意力的差距。
  - 注意：代理注意力分数和采样修正会引入额外计算与实现复杂度，实际部署加速需看 kernel 实现；评测主要集中在长上下文基准，对短上下文或特定任务的影响未充分讨论。
  - 学习指引：重点看方法：代理注意力分数如何定义、残余采样如何做包含概率修正、与 top-k/top-p/混合方法的统一关系；实验关注极端稀疏度下的稀疏-稠密差距、不同模型规模和长上下文基准上的收益，以及实际推理加速是否与理论一致。
  - 优先级依据：推理部署与性能优化方向，长上下文稀疏注意力是当前推理优化的核心问题，方法统一且有跨模型规模实验，值得当天重点看。

- [P0] [Looped Uniform Diffusion Language Models](https://huggingface.co/papers/2610.30066)（Hugging Face Daily Papers · 论文 · 模型架构与预训练 · 新 · 2026-10-22 · Saiteja Utpala, Chieh-Hsin Lai, Yuki Mitsufuji）
  - 中文摘要：该论文研究在均匀扩散语言模型（UDLM）中引入选择性循环（在每个去噪步骤内递归应用少量早期 Transformer 层），同时保持训练目标和采样器不变。UDLM 训练时需从可能不可靠的上下文中去噪，比掩码扩散语言模型更耗 FLOP，但下游推理性能更强。实验发现循环显著提升训练效率：在 OpenWebText 上以最多 2.8 倍更少训练 FLOP、在 FineWeb-Edu 上以 3.3 倍更少 FLOP 达到非循环 UDLM 约 0.5 万亿 token 训练的验证 NLL；在匹配 NFE 预算下，循环 UDLM 生成困惑度最多低 9.8%，大部分收益在中等循环次数时已实现。

  - 学习指引：重点看循环结构如何嵌入 UDLM 去噪步骤、iso-FLOP 对比实验设计、循环次数与收益的关系，以及生成困惑度和下游推理评测。对理解扩散语言模型训练效率和架构复用有参考价值，可结合代码看循环层的具体实现。
  - 优先级依据：模型架构与预训练方向，扩散语言模型是值得关注的非自回归路线，循环提升训练效率的结论对架构设计有直接参考价值。
- [P0] [Same Simulation, Different Evidence: Where Retrieved Tool Output Costs LLM Agents Accuracy](https://huggingface.co/papers/2610.26836)（Hugging Face Daily Papers · 论文 · Agent 与工具使用 · 新 · 2026-10-22 · Ke Zhang, Sahchit Chundur, Jerry Peprah Owusu）
  - 中文摘要：论文研究 LLM 智能体把长工具输出存到文件、按需检索读取时为何会损失准确率。作者用确定性地球化学模拟器 PHREEQC 构造 158 道可执行验证的选择题，发现通过章节索引而非上下文读取报告时，GPT-5.1 和 GPT-5.2 分别掉 11.3 和 7.9 分，而 Claude 模型无明显损失。重放 11,007 次模拟调用后，作者把失败归因于“证据替换”：模型跳过报告，改用自己更高精度的输出文件并错误舍入到相邻选项。
  - 亮点：提出“证据替换”这一失败模式，说明智能体准确率下降不一定来自计算错误，而可能来自回答所依据的证据被换掉。

  - 学习指引：重点看实验设计：如何用确定性工具保证每个打印值可追溯、如何区分“算对”与“答对”、如何通过重放调用定位证据来源。方法上值得学习的是把智能体失败拆解到证据链而非只看最终准确率。
  - 优先级依据：直接关系到智能体工具输出管理和上下文工程实践，对做 Agent 项目有即时提醒价值，值得当天重点看。

  - 中文摘要：论文关注 RAG 中的查询澄清问题：在多轮有据对话中识别查询是否歧义（包括查询本身通顺但与检索文档存在多种解释的情况），并生成澄清请求。作者构建约 3900 条样本的 ClariEdge 数据集，证明轻量 LoRA 微调模型在分类准确率（96.6%）和澄清质量上优于多个大模型提示基线，并强调 hard negatives 对区分真歧义与伪歧义的关键作用。
