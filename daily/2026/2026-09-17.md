- [P0] [ImpossibleRubrics: Stress-Testing Generated Rubrics as Reward Signals](https://huggingface.co/papers/2609.16816)（Hugging Face Daily Papers · 论文 · 评测与安全 · 新 · 2026-09-16 · Bowen Qin, Yi Xie, Yesheng Liu）
  - 中文摘要：这篇论文提出 ImpossibleRubrics 基准，专门测试语言模型生成的评分标准（rubric）作为奖励信号时的鲁棒性。它构造了 169 个“不可能任务”，即提示词诱导模型给出无依据结论，唯一诚实回答是承认任务不可完成；每个任务配有可验证的 oracle 证书，规定诚实答案可以声称什么、不可以声称什么，另有 48 个可回答对照任务。实验发现，在无偏的 150 个任务上，11 个生成器被对抗性答案“钻空子”的比例达 8%–26%，在刻意挑选的压力测试集上最强生成器仍被利用 36%。
  - 亮点：把“不可能任务”作为压力测试场景，用可验证证书而非固定 rubric 来检验奖励信号是否会被对抗答案利用，思路新颖且可复现。
  - 注意：基准规模较小（169 个任务），且“不可能任务”的构造可能带有作者主观判断；证书的覆盖范围未必能代表所有真实奖励场景。
  - 学习指引：重点看基准构造方法：如何定义六类不可能任务、如何编写可验证证书、如何生成并对抗测试 rubric。关注实验部分对 11 个生成器的对比，以及“无偏切分”和“压力切分”的差异。代码和数据若开源，应研究证书的验证逻辑，这直接关系到 rubric-based RL 和 LLM-as-a-judge 的奖励可靠性。
  - 优先级依据：直接关系到 rubric-based RL 和 LLM-as-a-judge 的奖励可靠性，是后训练与对齐中容易被忽视但影响很大的安全问题，值得当天重点看。

  - 优先级依据：涉及扩散语言模型架构与长程推理，属于模型架构方向的前沿工作，对理解 dLLM 有直接价值。
- [P0] [Latent Undertow: How Ordinary Typos Break Probes](https://arxiv.org/abs/2609.15994)（arXiv cs.CL · 论文 · 评测与安全 · 新 · 2026-09-16）
  - 中文摘要：论文发现，虽然 LLM 对普通拼写错误在行为上很鲁棒，但基于隐藏状态的恶意 prompt 探针却会被拼写错误严重干扰：在扰动 token 处读出向量旋转 43-56 度，并在约 10 个下游 token 内衰减到 15% 以下。每条消息叠加约 3 个常见拼写错误会让单位置 prompt 注入探针的 TPR@FPR=1% 下降 12 个百分点，仅靠重校准无法弥补。作者提出 KV-cache fork，在用户消息后追加固定短后缀让探针读取扰动下游几个 token，弥补了 95% 的差距。
  - 亮点：揭示了隐藏状态探针在普通拼写扰动下的脆弱性，并给出 KV-cache fork 这一简单有效的修复手段，对安全探针的工程部署有直接意义。
  - 注意：实验主要在较小规模模型上做探针评测，结论能否推广到更大模型和真实攻击场景需要验证；KV-cache fork 会增加推理开销。
  - 学习指引：重点看探针的读出位置与聚合方式（单位置、多位置、attention/max 聚合）的对比，以及旋转-衰减几何在不同模型（Llama-3.1-8B、Qwen3-8B、Gemma-4-E4B）上的复现。KV-cache fork 的实现细节和与扰动增强训练的对比也值得细看。
  - 优先级依据：安全探针鲁棒性是评测与安全方向的重要工程问题，方法简单且结论明确，值得当天重点看。
