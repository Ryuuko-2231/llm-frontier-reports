  - 中文摘要：论文研究 LLM Agent 在可访问文档上检索信息后，将多份非敏感信息拼合出敏感结论的“马赛克效应”泄露风险。作者用 30 个网络安全、医疗、军事合成案例，在受控模拟中收集三个 Agent 的 10800 条回答，并在两个开源 harness 中收集 1440 条真实 Agent 回答；即使查询本身可由单份文档回答，表现最好的 GPT-5.6-Sol 仍有 7.08% 的回答泄露禁止的复合结论，加入可见密级标头和显式聚合规则后，模拟回答中仍有 32.37% 不安全泄露，且拒绝率上升并不等于保密，因为拒绝本身可能暴露结论。

  - 优先级依据：Agent 数据安全是算法工程师落地 Agent 时必须考虑的工程问题，且给出了可复用的评测方法和防御失效证据，值得当天精读。

  - 中文摘要：该论文分析扩散语言模型在不同任务和语言上的计算成本差异：同样长度的输出，前向传播次数可能相差很大，从输入复制或轻微编辑的文本便宜，开放式写作昂贵；在 DiffusionGemma 中写故事每 token 所需前向次数是语法纠错的三倍以上，输出相对输入的新颖程度和词在任务内的稀有度能解释大部分差距，多语言场景中高 token 化语言也需要更多前向次数，且错误答案比正确答案消耗更多前向次数。
