  - 亮点：提出覆盖感知的证据到行动可靠性指标 NDR，揭示金融微调会系统性放大 BUY:SELL 比例。

  - 优先级依据：该基准针对金融 VLM 的证据到行动可靠性，评测设计新颖且对安全与评测方向有直接启发，值得当天重点阅读。

  - 亮点：通过组合独立后训练模型的策略偏移，在单学生模型中同时提升推理准确率和推理效率。

  - 优先级依据：该工作提出后训练阶段组合能力的新范式，对推理模型效率优化有直接工程价值，值得当天重点阅读。

- [P0] [Learning to Solve Hard Problems in RL for LLMs by Never Giving Up](https://huggingface.co/papers/2609.13443)（Hugging Face Daily Papers · 论文 · 后训练与对齐 · 新 · 2026-09-15 · Michael Noukhovitch, Hamish Ivison, Nathan Lambert）
  - 中文摘要：该论文指出 RL 训练 LLM 时存在马太效应：模型在已经擅长的简单问题上提升大，在困难问题上提升小。作者认为现代 RL 方法在简单问题上浪费了过多计算，应动态重新分配计算。为此提出 Never Give Up（NGU），一种简单的自适应采样方法，持续为某个问题生成样本直到有一个正确，借助异步 RL 自然减少简单问题的采样并更多计算用于困难问题。作者研究了影响 NGU 的设计选择，如 off-policy 鲁棒性，并总结最佳实践。在数学基准 Deepscaler 上，NGU 提升了每单位计算的性能，尤其在困难问题上；在代码任务 Manufactoria 上，标准 GRPO 表现不如 NGU。
  - 亮点：提出 Never Give Up 自适应采样，通过持续生成直到正确来将计算从简单问题重新分配到困难问题。
  - 注意：方法依赖异步 RL 基础设施，实现复杂度较高；实验主要集中在数学和代码任务，向其他领域 RL 训练的迁移效果需进一步验证。
  - 学习指引：重点理解马太效应的定义和实验证据：RL 在简单与困难问题上的提升差异。关注 NGU 的自适应采样机制如何与异步 RL 结合，以及 off-policy 鲁棒性等设计选择的影响。对比标准 GRPO 与 NGU 在 Deepscaler 和 Manufactoria 上的性能-计算曲线，思考计算分配策略对 RL 训练效率的普遍意义。
  - 优先级依据：该工作揭示 RL 训练中的计算分配问题并提出可操作的改进方法，对后训练与对齐方向有直接实践价值，值得当天重点阅读。
- [P0] [Expert-Space Exploration in MoE Reinforcement Learning](https://huggingface.co/papers/2609.13058)（Hugging Face Daily Papers · 论文 · 模型架构与预训练 · 新 · 2026-09-15 · Hongyi He, Zhenghao Lin, Xiao Liu）
  - 中文摘要：这篇论文关注 MoE 大模型在强化学习后训练中的专家路由问题。作者发现扰动专家路由会像提高解码温度一样增加 rollout 多样性，但直接扰动会激活不合适的专家、显著降低 rollout 质量。为此提出 ESRL 框架：保留高置信度专家作为锚点，只在合理候选池内做随机路由，并根据 router 熵自适应调整扰动强度，从而在保持可靠计算路径的同时探索专家空间。
  - 亮点：把 MoE 的专家选择从固定组件变成 RL 中可探索的多样性来源，且用锚点与候选池约束避免质量崩塌。
  - 注意：扰动路由可能增加训练不稳定性和计算开销，论文摘要未给出大规模模型上的完整消融，需确认其在不同 MoE 结构上的泛化性。
  - 学习指引：重点看方法部分：锚点专家如何选取、候选池如何构造、router 熵如何驱动扰动强度自适应；同时关注实验中对 rollout 多样性与质量的权衡，以及相比标准 MoE RL 后训练的稳定性与效率对比。代码若开源，应看路由扰动是否引入额外推理开销。
  - 优先级依据：MoE 架构与 RL 后训练交叉方向，对理解稀疏模型训练和 rollout 多样性有直接帮助，属于当天值得重点看的内容。
- [P0] [Root-Cause Attribution Is a Search Problem: Continual Search for Long-Horizon Agent Failures](https://huggingface.co/papers/2609.13463)（Hugging Face Daily Papers · 论文 · Agent 与工具使用 · 新 · 2026-09-15 · Harsh Raj, David Lee, Anas Mahmoud）
  - 中文摘要：这篇论文研究长程 Agent 执行日志中的失败根因归因问题。作者指出，现有基于 LLM 的一次性判断方法在长轨迹上容易过早锁定一个看似合理的诊断，忽略分散在远处动作中的关键证据，因此把 RCA 建模为大规模搜索问题。论文提出 Continual Search 迭代框架，通过多轮引导让 judge 持续寻找未解决的诊断证据，并在四个 RCA 基准上评估。
  - 亮点：把 Agent 失败诊断从一次性 LLM 判断转化为持续搜索过程，更贴合长程轨迹中证据稀疏分布的特点。
  - 注意：迭代搜索会显著增加 LLM 调用次数和诊断成本，且论文摘要未说明在真实生产日志上的可扩展性。
  - 学习指引：重点看 Continual Search 的迭代机制：每轮如何提示 judge、如何判断证据是否已充分、如何避免重复搜索；同时关注四个基准的构造方式和长轨迹下的诊断准确率提升幅度。局限部分应留意搜索轮数增加带来的成本与延迟。
  - 优先级依据：Agent 可靠性与失败归因是当前工程落地的关键问题，方法思路清晰且可迁移到自己的 Agent 项目调试中。
