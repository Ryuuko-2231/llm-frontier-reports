  - 中文摘要：该论文针对“是否应该用大语言模型（LLM）替代传统文本嵌入模型”这一核心问题，进行了成本感知的受控对比实验。研究涵盖了6个系列的10个LLM和26个嵌入模型（参数规模从1.18亿到140亿），在37个任务（包括分类、语义文本相似度、聚类、对分类和检索）上进行了评估。结果显示，两种范式在整体性能上几乎持平（最佳LLM得分为77.6，最佳嵌入模型为77.2），但优势领域不同：LLM在推理密集型检索上领先，嵌入模型在分类上领先，而在聚类、STS和对分类上两者相当。然而，达到这种性能平价的成本差异巨大：LLM的成本最高可达嵌入模型的1431倍（每次基准测试通过成本为154美元对比0.11美元），且开源LLM在同一GPU上的处理速度慢2.5到736倍。推理token占LLM推理成本的28%到81%，而降低推理预算在大多数模型的消融实验中能保持甚至提升检索质量。帕累托前沿包含领先的嵌入模型和唯一的LLM——Gemini 3.1 Pro。研究支持分工的观点：根据任务类型选择使用嵌入模型或LLM。
  - 亮点：通过大规模受控实验揭示了LLM和嵌入模型在不同任务上的优势互补，并提出了成本感知的帕累托前沿，为实际系统设计提供了量化依据。
  - 注意：论文的结论基于特定模型和任务集，可能不适用于所有场景；且成本计算可能未涵盖所有部署开销（如硬件、能耗），实际应用时需结合具体环境验证。

  - 优先级依据：该论文深入探讨了后训练（SFT和RL）对模型行为的影响，并提出了创新的评估维度，对理解后训练的本质和评估方法有重要价值，值得重点学习。

  - 中文摘要：FlowEvo是一个无需训练的框架，通过工作流和可执行技能的协同进化来提升LLM代理的性能。它将在推理过程中成功的工作流编译为可调用的技能，存储在持久化技能库中，并在后续任务中通过直接执行或作为上下文来检索使用。同时，它跟踪每个技能的下游效用，并抑制导致负迁移的技能。使用共享的GPT-4o-mini骨干，FlowEvo在ALFWorld、HumanEval、MBPP、GSM8K和MATH-500的完整标准分割上，在8个基线中取得了最高准确率。在ALFWorld上达到85.6%，比最强基线高26.4个百分点，同时使用的token约为三分之一。在10个基础模型（7B到671B参数）上，FlowEvo在50个模型-数据集比较中胜过ExpeL 49次。代码已开源。
  - 亮点：通过工作流与技能的协同进化，实现了无需训练即可显著提升Agent性能，且token效率高，在多个基准上超越强基线。

  - 学习指引：学习时应重点关注FlowEvo的框架设计（如何将工作流编译为技能、技能库的存储与检索机制、负迁移抑制策略）、实验设置（基线选择、数据集、token效率对比），以及代码实现（如何复现）。同时，思考这种自我进化机制与现有Agent框架（如ReAct、Reflexion）的区别。
  - 优先级依据：该论文提出了一种新颖的Agent自我进化框架，对Agent设计有重要启发，且实验充分、代码开源，适合作为项目参考，值得当天重点学习。
- [P0] [Hierarchical Self-Improvement: A Framework for Task-Specific Evolvable Agent Harnesses](https://huggingface.co/papers/2608.08466)（Hugging Face Daily Papers · 论文 · Agent 与工具使用 · 旧 · 2026-08-21 · Tailin Zhou）
  - 中文摘要：该论文提出了层次化自我改进（HSI）框架，研究如何让LLM代理的“装备”（harness）——即可执行脚手架——针对特定任务持续进化。HSI使用一个冻结的LLM M，在三个层次上操作：任务装备H执行任务，进化器重写H，元进化器在冻结的外锚下重写进化器的策略代码。通过思考开关设计，在任务执行时禁用推理，在自我修改时启用，以隔离装备进化的贡献。HSI受两个因素限制：反馈保真度（进化需要信息丰富的奖励信号）和骨干能力（装备重设计无法克服冻结模型的限制）。在BALROG上使用DeepSeek-V4-Flash-Preview进行了实验（摘要截断）。
  - 亮点：提出了层次化自我改进框架，使装备能够持续进化，并通过思考开关设计隔离了装备进化的贡献，为Agent自我改进提供了新思路。
  - 注意：论文摘要截断，实验细节不完整；且框架依赖环境反馈，在奖励信号稀疏的任务中可能效果有限。
  - 学习指引：学习时应重点关注HSI的层次化设计（如何划分任务、进化器、元进化器的职责）、思考开关的作用、以及论文提出的两个限制因素（反馈保真度和骨干能力）。同时，思考这种自我进化框架与FlowEvo等方法的异同，以及如何应用于实际任务。
  - 优先级依据：该论文与FlowEvo同属Agent自我改进方向，但侧重点不同（装备进化 vs 技能进化），对理解Agent的自我改进机制有互补价值，且框架设计新颖，值得重点学习。
